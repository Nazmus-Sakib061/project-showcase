# Screenshot Safety Checklist

This folder is reserved for approved, sanitized portfolio screenshots.

## Before adding any image

Confirm that the image contains none of the following:

- Client or office name, logo, or branding
- Customer, tenant, patient, doctor, facility, or mailbox data
- Email address, phone number, home address, or payment information
- Server URL, private repository name, credential, token, or admin screen
- Production metrics, private invoices, attachments, or confidential business data
- Paid theme, plugin, or other restricted asset

## Safe screenshot standard

- Use fake or demo data.
- Add a clear Demo label where appropriate.
- Redact sensitive areas instead of relying on blur when possible.
- Prefer cropped, low-resolution, or watermarked images for portfolio use.
- Keep the original private image outside this public repository.
- Verify that the image does not reveal proprietary source-code structure.

## Current status

No project screenshot has been added yet. Screenshots should be added only after individual safety review and approval.

A screenshot can still be downloaded or copied once published. This checklist protects sensitive content; it cannot prevent copying of a public image.
