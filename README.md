# Nazmus Sakib — Project Showcase

A public, sanitized portfolio layer for selected web applications, business systems, prototypes, and testing work.

## Public/private boundary

This repository contains case-study content only. It does not contain proprietary source code, secrets, client or office data, mailbox attachments, real customer or tenant data, production URLs, database dumps, credentials, or copied commercial assets.

All source repositories remain private where appropriate. Screenshots and demos are added only after safety review. Any public demo must use fake data and a clear Demo label.
